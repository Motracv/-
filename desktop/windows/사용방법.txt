학교용병단 — Windows 실행 파일 v1.0.0

1. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 '모두 압축 풀기'를 선택하세요.
2. School-Mercenaries.exe를 더블 클릭하세요.
3. 홈페이지를 거치지 않고 학교용병단 게임이 전용 창으로 열립니다.
   친구에게는 ZIP 파일 그대로 전달하면 됩니다.

실행 환경
- Windows 10 / 11, 64비트(x64)
- Microsoft Edge 또는 Google Chrome이 설치되어 있어야 합니다.
- 처음 실행할 때 인터넷 연결이 필요합니다.
- 이 파일은 설치 없이 실행하는 게임 전용 실행기입니다.
  PC에 있는 브라우저 엔진으로 운영 중인 게임을 엽니다.
  게임 전체와 브라우저 엔진을 포함한 독립 설치 패키지는 아닙니다.
- 창을 닫으면 종료됩니다. 원한다면 EXE의 바로 가기를 바탕 화면에 만드세요.

저장과 계정
- 기본 브라우저가 Chrome이면 Chrome을, 그 외에는 Edge를 우선 사용합니다.
  선택한 브라우저가 없으면 설치된 다른 브라우저를 찾습니다.
- 해당 브라우저의 기본 프로필을 사용합니다. 이전에 사용한 브라우저나
  프로필이 다르면 게스트 저장이 다르게 보일 수 있습니다.
- 계정 기록은 게임 안에서 같은 Google 계정으로 로그인해 이어가세요.
  Google 로그인·계정 저장·랭킹에는 인터넷 연결이 필요합니다.
- 게스트의 오프라인 플레이는 온라인에서 게임 파일 준비를 마친 뒤 가능합니다.
  브라우저 데이터를 지우면 게스트 저장 및 오프라인 파일도 삭제될 수 있습니다.
- 여러 게임 창을 동시에 열어 진행하지 않는 것을 권장합니다.
- 브라우저를 직접 선택하려면 EXE의 바로 가기 → 속성 → 대상 맨 뒤에
  한 칸을 띄우고 --chrome 또는 --edge를 붙이세요.

업데이트와 파일 확인
- 게임은 기존 온라인 버전으로 업데이트됩니다. 새 버전이 준비되면
  열려 있는 학교용병단 창을 모두 닫고 다시 실행하세요.
- 실행기에는 유료 코드 서명 인증서를 적용하지 않았습니다.
  Windows에서 '알 수 없는 게시자' 또는 SmartScreen 알림이 나올 수 있습니다.
  출처를 확인할 수 없는 수정 파일은 실행하지 마세요.

검증 범위
- Windows x64 실행 파일로 교차 빌드합니다.
- 실제 Windows PC에서의 화면·로그인·설치 경고 동작은 별도 확인이 필요합니다.
