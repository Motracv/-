은빛 우산 · 스킬 체험실

공개 경로: /previews/parasol-skills/
독립된 시연 화면입니다. 게임 계정, 재화, 전투 저장 데이터와 연결하지 않습니다.

직접 사용
- 우산 사격: 마지막 표적에 명중. 버튼 또는 1 / Q.
- 관통탄: 세 표적에 순서대로 명중. 버튼 또는 2 / E.
- 부채 스킬: 동작 잔상과 곡선 파동. 버튼 또는 3 / R.
- 이동: A / D 또는 방향키, 모바일은 이동 버튼 길게 누르기.
- 회피: Space 또는 회피 버튼. 발사 전 준비 동작을 취소할 수 있습니다.
- 시전 중 누른 스킬은 다음 동작으로 이어집니다. 마지막 입력 1개를 보관합니다.
- 잔상 / 별빛·꽃잎 연출, 연속 시연, 일시 정지, 속도 조절, 초기화.
