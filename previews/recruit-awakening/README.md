# 교실에서의 첫 만남 — 모집 연출 시안

별도 정적 미리보기입니다. 실제 계정, 보석, 보유 캐릭터, 뽑기 확률과 연결하지 않습니다.
`index.html`에서 UR 호라스 / SSR 오시아 / SR 나리를 선택해 재생합니다.

- 0–1초: 서서히 암전
- 1–3.3초: 교실과 책상에 엎드려 잠든 단장
- 3.3–5초: 동료의 실루엣과 최고 등급의 빛
- 5–7.6초: 두 번 깨우는 동작과 대사
- 7.6–8.7초: 돌아보기와 눈을 뜨는 전환
- 8.7–10.5초: 벚꽃 / 물 / 치유 문양 공개
- 10.5–12.4초: 문양을 통과하는 빛의 통로, 원근 고리와 광선
- 12.4–13초: 광량 상승, 파동, 짧은 진동, 캐릭터 등장
- 13–16초: 얼굴 가까이에서 전신으로 부드럽게 이동, 미소 전환, 손 흔들기와 인사
- 이후: 사용자가 누를 때까지 대기 → 원래 순서의 10명 결과

교실·단장·동료·전후경 효과·자막은 분리된 레이어입니다. v2는 세 캐릭터에 각각 4개의 새 전신 포즈를 제공합니다. `frames.js`의 원화 영역을 동일한 키와 발 기준에 맞춰 그리므로 SR/SSR의 상반신 확대 문제를 제거합니다. 포즈 전환 외에 64개 가로 스트립의 미세 변형으로 옷·머리카락의 움직임을 보간하고, 인사 손은 별도 영역으로 회전합니다. 이 4장은 키 포즈 원화이며 60장의 독립 작화라는 뜻은 아닙니다.

`cinema.js`가 문양·회전 마법진·원근 통로·파동·입자를 화면마다 그립니다. 입자는 최대 160개, 효과 Canvas는 각각 약 220만 픽셀, 캐릭터 Canvas는 약 160만 픽셀로 제한합니다. 4K 화면에서도 등급별 캐릭터 배치는 같은 기준을 쓰며 효과 해상도와 DOM 텍스트 해상도는 독립적입니다. 치유 문양은 나리의 역할에 맞춘 시안이며 실제 게임의 속성/성능을 변경하지 않습니다.

기존 배경 1672×941 및 새 원화 6장은 원본 크기의 무손실 WebP이며 4K 원화는 아닙니다. `assets/manifest.json`에 v1과 v2 원본 출처, 크기, 바이트 수를 기록했습니다. 압축 영상/GIF는 사용하지 않습니다.

`model.js`의 `highest()`는 결과 중 UR > SSR > SR > R 순으로 최고 등급을 고르고, 같은 등급은 먼저 받은 캐릭터를 선택합니다. 다시 재생해도 결과는 바뀌지 않습니다. 실게임 통합 시 서버에서 이미 확정된 결과를 표시하는 역할만 해야 하며 재생/건너뛰기가 재요청이나 보상 지급을 해서는 안 됩니다.

`preview.js`는 하나의 프레임 루프, 숨긴 탭의 시간 정지, 취소 가능한 재생, 오래된 로딩 결과 무시, 이미지 실패 재시도, 제한된 입자 수를 사용합니다. 효과음은 기본 꺼짐이며 버튼으로 켤 수 있습니다. 동작 줄이기 설정에서는 인사 장면으로 전환합니다.

검증:

```sh
node --check previews/recruit-awakening/model.js
node --check previews/recruit-awakening/preview.js
node --check previews/recruit-awakening/cinema.js
SCHOOL_DOM_MODULE=/tmp/overhaul-dom/node_modules/linkedom node tests/school-recruit-preview.cjs
node tests/school-recruit-cinema.cjs
```

테스트는 결과 선택·장면 진행·중복 클릭·정지/재개·백그라운드 전환·연속 등급 선택·로딩 실패 복구·동작 줄이기·자산 경로·본게임 데이터와의 분리를 검사합니다. 추가로 실제 Canvas 렌더러로 39개 포즈 보간, 54개 속성 효과 샘플, 세로 화면, 캐릭터별 동일 키/발 기준, 효과 픽셀 예산을 검사합니다. 현재 작업 환경에는 지원되는 브라우저 검증 도구가 없어 실제 브라우저 UI나 기기별 프레임률 검사는 하지 못했습니다.
