# 학교용병단 이미지

## 오시아

`osia-sprites.png`는 사용자가 제공하고 확정한 오시아 외형 시안에서 제작한 투명 배경 이미지입니다. 2172×724 RGBA PNG에 724×724 셀 세 개를 가로로 배치했습니다. 왼쪽부터 대기, 마력 집중, 발사이며 모두 오른쪽을 바라봅니다. 발 위치를 같은 기준선에 맞춰 `SchoolArt.hero()`가 같은 위치에 그립니다.

파란 단발·주황 지느러미·흰 상의·검은 치마·하얀 스타킹·갈색 롱부츠의 용왕 외형을 유지합니다. 전체 캐릭터는 각 셀 안에 포함되며 수룡·파도·스킬 컷인은 이미지에 합성해 넣지 않고 Canvas 전투 이벤트에 따라 별도로 그립니다.

## 라바

`lava.png`는 사용자가 제공한 참조 외형을 바탕으로 **image_gen** 도구에서 새로 생성한 투명 배경 이미지입니다. 파란 머리·한복·부채를 사용하는 남성 인간 무당이며 오른쪽을 바라봅니다. 1122×1402 RGBA PNG, 737,629바이트입니다. 생성 결과를 픽셀 편집이나 리사이즈 없이 그대로 복사해 배포 자산으로 저장했습니다.

생성 원본의 작업 파일명은 `exec-4f1c9dee-6f7b-47d4-a92d-00fe462b2441.png`입니다. 배포 파일은 그 원본과 같은 내용이며 원본 파일 자체를 변경하거나 삭제하지 않았습니다.

이미지 파일은 유지하고 `art.js`의 `drawImage()`에서 원본 영역 `(x:245, y:91, width:631, height:1260)`을 선택해 투명 여백을 제외합니다. 전투 표시 높이는 논리 좌표 44이며 다른 출전 용병과 발 기준선을 맞춥니다. 이는 표시할 때의 좌표 선택이며 파일을 잘라 재저장하는 과정이 아닙니다. 현재 라바는 단일 캐릭터 이미지이며, 부채·바람·회복·방어막·긴급생존 동작 효과는 Canvas에서 별도로 그립니다.

## 던전 선택 일러스트

세 이미지는 학교 이세계 도트 분위기로 **image_gen**에서 각각 생성한 1536×1024 PNG입니다. 생성 결과를 크롭·리사이즈·픽셀 편집 없이 그대로 복사했습니다. 각각 던전 선택 카드의 배경으로 사용하며 그림 자체에 보상이나 조작 글자를 넣지 않습니다.

| 배포 파일 | 장면 | 생성 원본 작업 파일명 |
| --- | --- | --- |
| `dungeon-daily.png` | 마법 물자가 쌓인 방과 후 보급고 | `exec-2dc15a4b-edac-45db-b4bb-03081795b445.png` |
| `dungeon-weekly.png` | 마법으로 봉인된 이사장실 | `exec-4ae4e8ce-6af8-4a03-9464-76fcb4d976a9.png` |
| `dungeon-tower.png` | 끝없이 이어지는 뫼비우스의 학교 복도 | `exec-8e523f39-83de-4a66-ade6-ef2abcf218ba.png` |

카드 크기에 맞춰 CSS로 보이는 영역을 조절하며 원본 PNG는 수정하지 않습니다. 이미지가 로딩되지 않아도 던전 이름·난이도·열쇠·보상과 입장 조작은 별도 HTML로 표시합니다. 일반 적 36종의 도트 모습은 `art.js`가 그리며 이 배경 이미지에 합성하지 않습니다.

## 표시와 복구

전투·도감·모집 배너·결과·편성·상세 정보는 같은 이미지 소스를 사용합니다. 초상화는 `SchoolArt.portrait()`에서 160×192 Canvas로 그려 캐시합니다. 이미지 로딩에 실패하면 `art.js`에 직접 그린 오른쪽 방향 도트 대체 캐릭터를 표시합니다. 라바 대체 그림도 남성 인간 한복 외형과 부채를 유지합니다. `SchoolArt.assetsReady('osia' | 'lava')`로 각 이미지의 로딩 상태를 확인합니다.

이미지는 저장소의 정적 파일로 제공하며 실제 플레이 중 이미지 생성 API나 외부 이미지 사이트에 의존하지 않습니다. 참조 시안과 생성 원본은 작업 자료로 유지하고 게임 배포에는 위 PNG 자산을 사용합니다.
