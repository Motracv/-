# 오시아 전투 스프라이트

`osia-sprites.png`는 사용자가 제공하고 확정한 오시아 외형 시안에서 제작한 투명 배경 이미지입니다. 2172×724 PNG에 724×724 셀 세 개를 가로로 배치했습니다. 왼쪽부터 대기, 마력 집중, 발사이며 모두 오른쪽을 바라봅니다. 발 위치를 같은 기준선에 맞춰 `SchoolArt.hero()`가 같은 위치에 그립니다.

전체 캐릭터는 각 셀 안에 포함되며 큰 물의 용·파도는 이미지에 굽지 않고 Canvas 전투 이벤트에 따라 별도로 그립니다. 이미지 로딩 실패 시에는 오른쪽을 바라보는 소형 도트 대체 그림을 표시합니다. 원본 시안·생성 파일을 삭제하거나 외부에 따로 게시하지 않습니다.
