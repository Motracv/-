# Equipment icons

Nine original SVG pixel icons authored for 학교용병단. Each file is a self-contained 64 × 64 image with integer-aligned geometry, `shape-rendering="crispEdges"`, a Korean accessible title, and transparent outer corners. No external artwork, fonts, scripts, filters or linked images are used.

The item silhouette identifies its purpose. R uses a blue-gray frame with one bottom pip, SR a violet frame with two pips, and SSR a gold frame with three pips. The pips supplement the color cue. The inventory should also display the item name and rarity as text.
