# Guild and profile art

Original pixel-art assets generated for 학교용병단 using image_gen on 2026-11-18; no third-party game artwork is included.

- `classroom.png`: warm fantasy school classroom background.
- `crests.png`: three equal columns: crimson shield, navy star, emerald book. CSS selects one emblem per guild.
- `avatars.png`: 3 columns × 2 rows: knight, witch, scholar, bear, cat, bird. CSS selects each portrait; the existing leader-character portrait remains available.

The static art does not add a per-frame animation loop. All three images are included in the installed game's versioned offline cache.
