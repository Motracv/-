개인정보 안내

적용일: 2026년 11월 17일

Google 로그인은 선택 사항입니다. 로그인하지 않아도 닉네임과 초대 코드로 게스트 대전을 할 수 있습니다.

저장하는 정보와 목적

로그인 확인에는 Google이 서명한 인증 응답을 사용합니다. 게임은 Google 계정의 고유 식별자를 해시한 값, 임의의 게임 계정 번호, 계정 생성 시각, 로그인 세션의 해시와 만료 시각을 저장합니다. 비밀번호, Google 실명, 이메일 주소, 프로필 사진은 게임 데이터베이스에 저장하지 않습니다.

서버가 확정한 온라인 경기의 승리·패배·무승부, 경험치, 지급 여부와 사유, 종료 시각을 저장해 레벨과 전적을 계산합니다. 방 참가 시 선택한 닉네임과 해당 시점의 레벨·칭호는 그 방의 다른 참가자에게 보입니다. 다른 참가자의 비공개 손패와 계정 식별 정보는 공개하지 않습니다.

학교용병단은 같은 로그인 계정을 사용합니다. 계정으로 플레이하면 보유 용병·편성·레벨·각성·재화·모집 내역·임무·자동 전투·방치 보상·갱신 시각을 서버에 저장합니다. 중복 지급을 막기 위해 최근 20개 행동의 요청 번호와 결과도 보관합니다. 학교용병단의 성장 기록은 카드게임과 별개이며 다른 플레이어에게 공개하지 않습니다. 게스트 진행은 해당 브라우저에만 저장하고 계정 진행과 합치지 않습니다.

처리 서비스와 보관

게임 화면은 GitHub Pages, 온라인 게임 및 계정 저장소는 Sites의 Cloudflare Worker·D1에서 운영합니다. Google 로그인을 선택할 때 Google Identity Services에 연결합니다. 각 서비스는 연결 처리에 필요한 IP 주소·브라우저 정보 등을 자체 정책에 따라 처리할 수 있습니다.

계정과 전적은 게임 계정 삭제 시까지 보관합니다. 로그인 세션은 7일 후 만료하며, 브라우저 탭에는 세션용 토큰을 보관합니다. 일회용 로그인 요청은 10분 후 만료합니다. 만료된 로그인 자료는 후속 로그인 요청에서 정리됩니다. 게임 방은 생성 후 6시간 동안 유효하며 만료된 방은 후속 방 생성 시 정리됩니다. 경험치 저장이 일시 실패한 종료 방은 지급을 복구한 뒤 정리합니다.

로그아웃과 삭제

카드게임의 메뉴 → 내 계정에서 로그아웃하거나 게임 계정을 삭제할 수 있습니다. 삭제하면 모든 로그인 세션, 카드게임의 레벨·경험치·전적, 학교용병단의 계정 진행 전체와 Google 계정 연결 식별 정보가 제거됩니다. 이미 참가한 방의 임시 닉네임과 경기 상태는 방 정리 시 사라집니다. Google 계정 자체는 삭제하지 않습니다. 다시 로그인하면 새로운 레벨 1 게임 계정이 생성됩니다. 학교용병단의 게스트 전환은 계정 삭제가 아닙니다.

브라우저에는 효과음·화면 설정 및 현재 방 복귀 정보, 학교용병단 게스트 진행과 저장 방식, 처리 중인 학교용병단 행동 요청을 저장합니다. 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다. Google 로그인 스크립트는 계정 창에서 로그인을 준비할 때만 불러옵니다.
