# Google 로그인 연결

2026-11-17 운영자가 제공한 OAuth 클라이언트 ID를 설정하고 Google 로그인을 활성화했습니다. 실제 게임의 Google 공식 버튼과 Google 로그인 화면 연결을 확인했습니다. 계정 로그인 완료·재접속·계정별 경험치 지급의 운영 확인은 사용자가 본인 계정으로 로그인한 뒤 진행합니다. 테스트 서명 검사는 실제 Google 계정 로그인 검증과 구분합니다. 클라이언트 보안 비밀번호는 사용하지 않습니다.

## 운영자가 한 번 할 설정

1. https://console.cloud.google.com/auth/overview 에서 프로젝트를 선택하거나 만듭니다.
2. **Google Auth Platform → 브랜딩**에 앱 이름, 사용자 지원 이메일, 개발자 연락처를 입력합니다.
3. **대상**을 외부 사용자로 설정합니다. 테스트 중에는 **테스트 사용자**에 본인과 검증할 친구의 Google 계정을 추가합니다. 친구들에게 정식 제공할 때는 Google 콘솔의 게시 상태를 확인하고 운영 모드로 전환합니다.
4. **클라이언트 → 클라이언트 만들기 → 웹 애플리케이션**을 선택합니다.
5. **승인된 JavaScript 원본**에 정확히 `https://motracv.github.io`를 넣습니다. `/-/game.html` 경로와 끝 슬래시는 넣지 않습니다. 로컬 검증용 원본은 필요할 때만 별도로 추가합니다.
6. 이번 구현은 Google Identity Services의 팝업 로그인 버튼과 ID 토큰 콜백을 사용합니다. **승인된 리디렉션 URI는 필요 없습니다.**
7. 생성된 `…apps.googleusercontent.com` 형식의 **클라이언트 ID**를 전달합니다. 공개 식별자이므로 비밀키가 아닙니다. **클라이언트 보안 비밀번호는 전달하거나 저장하지 않습니다.**

브랜딩에서 사이트 주소를 요청하면 다음을 사용합니다.

- 게임: https://motracv.github.io/-/game.html
- 개인정보 안내: https://motracv.github.io/-/privacy.html
- 운영자 이메일: 운영자 본인의 연락 가능한 이메일을 입력합니다.

Google이 도메인 확인이나 앱 검증을 요구하면 해당 콘솔 안내를 따라야 합니다. Google 콘솔은 게임 서버 설정만으로 대신 완료할 수 없습니다.

## 서버 연결

Sites project `appgprj_6afb8f3aa8cc8191b256dffc1b94eccc`의 운영 환경 변수 **`GOOGLE_CLIENT_ID`**에 ID를 설정하고 해당 버전을 다시 배포합니다. 환경 변수는 Sites에서 관리하며 GitHub 소스나 `.openai/hosting.json`에 넣지 않습니다. 이 값 자체는 공개 값이며 클라이언트 설정 API가 로그인 버튼에 제공합니다.

`GET /api/account/config`의 `enabled: true`와 올바른 `clientId`를 확인합니다. 설정 전에는 `enabled: false`이며 계정 창은 연결 준비 중이라고 표시하고 기존 게스트 대전은 작동합니다. 로컬 `server.cjs`는 메모리 기반 연습 서버이므로 계정 저장을 제공하지 않습니다. 계정의 실제 운영 경로는 D1 Worker입니다.

## 경험치와 계정 정책

- 온라인 완주 30 XP, 승리 추가 50 XP, 무승부 추가 10 XP.
- 로그인한 서로 다른 참가자 2명 이상, 경기 60초 이상, 해당 참가자의 유효한 카드 사용·방어·교환·합성 2회 이상이 조건입니다. 넘기기는 참여 횟수에 포함하지 않습니다.
- 살아 있을 때 기권하거나 90초 연결 종료로 탈락한 참가자는 경험치를 받지 않습니다. 이미 정상 탈락한 뒤 방에서 나가는 것은 기권이 아닙니다.
- 조건을 못 채워 경험치가 0인 경기도 서버가 확정한 온라인 승패는 전적에 기록됩니다. 게스트와 AI 연습은 계정 전적·경험치를 저장하지 않습니다.
- Lv.1에서 다음 레벨까지 100 XP, 이후 요구량은 레벨마다 50 XP 증가합니다. 누적 필요량은 `25*(L-1)^2 + 75*(L-1)`입니다.
- Lv.5 도전자, 10 듀얼리스트, 20 베테랑, 30 마스터, 50 전설. HP·카드 효과·뽑기 확률은 레벨에 영향받지 않습니다.
- Google 실명·이메일·사진은 게임 DB에 저장하지 않습니다. 방의 게임 닉네임과 레벨·칭호만 상대에게 보입니다.
- 로그인 계정은 **방 입장 시** 연결됩니다. 참가 중에는 계정 변경 UI를 막습니다. 같은 계정의 한 방 중복 참가는 서버에서도 거부합니다.

## 검증과 저장

Google RS256 서명과 고정 HTTPS 인증 키, 발급자, 수신 클라이언트, 발급/만료 시각, 일회용 nonce를 서버에서 확인합니다. 앱 세션은 256비트 임의 토큰이며 DB에는 해시만 저장하고 7일 후 만료합니다. 브라우저에는 해당 서버 전용 sessionStorage에 보관합니다. 로그아웃 시 현재 세션을 폐기하며 게임 계정 삭제 시 모든 세션과 레벨·전적을 삭제합니다.

영구 경험치 원장은 `(match_id, account_id)` 고유 키로 중복 지급을 막습니다. 서버가 확정한 경기만 원장에 넣으며 클라이언트에는 XP 지급 API가 없습니다. 경기 결과 저장 후 지급이 일시 실패하면 다음 방 요청 또는 본인의 계정 조회에서 복구합니다. 미지급 결과는 방 접근 기한이 지나도 원장에 저장되기 전까지 정리하지 않습니다. 원장은 계정 삭제 시 제거됩니다.

운영 전 마지막 확인: 실제 Google 계정 로그인 → 새로고침 → 별도 브라우저에서 같은 계정으로 동일 레벨 확인 → 서로 다른 계정 2~5명 대전 → 최종 경험치·레벨·전적 동기화 → 로그아웃/재로그인. 실제 사용자 계정 검증을 수행하기 전에는 Google 로그인 연결 완료로 보고하지 않습니다.

## 학교용병단 계정·이름·랭킹

학교용병단은 같은 원본의 [school.html](https://motracv.github.io/-/school.html)에서 같은 Google 로그인 설정과 게임 세션을 사용합니다. 추가 Google 동의 범위·OAuth 원본·클라이언트 비밀번호는 필요하지 않습니다. 학교 진행은 `school_saves`에 저장하며 카드게임 경험치·칭호와 별개입니다. 용병 최대 100레벨·단장 최대 200레벨 규칙은 학교 게임에만 적용합니다.

단장 이름은 사용자가 고르는 게임 닉네임입니다. 서버에서 글자와 길이를 검증하며 Google 실명이나 이메일을 이름으로 가져오지 않습니다. 공개 랭킹에는 서버가 확정한 계정 기록의 순위·단장 이름·단장 레벨·복도 최고 층만 표시합니다. 이름을 정하지 않은 계정은 `새내기 단장`으로 표시합니다. Google 식별 정보·게임 계정 ID·토큰·보유 용병·재화·전체 저장은 랭킹에 공개하지 않습니다.

게스트는 랭킹 목록을 볼 수 있지만 기기 진행을 계정에 합치거나 순위에 제출하지 않습니다. 저장·행동 API는 로그인한 계정만 사용하며 공개 목록 API도 유효한 세션이 있을 때만 본인 전체 순위를 반환합니다. 게임 계정 삭제 시 학교 저장과 공개 랭킹 항목도 제거합니다. 상세 공개 범위는 [개인정보 안내](../privacy.html), API와 배포 설정은 [서버 운영 안내](HOSTING.md)를 참고하세요.

배포 후 실제 계정 검증에는 학교 진행 불러오기 → 단장 이름 변경 → 다른 브라우저 동기화 → 랭킹의 본인 표시와 게스트 목록 확인을 포함합니다. 기기 저장과 계정 저장을 섞지 않으며, 이 확인 절차를 문서에 적은 것만으로 실제 사용자 계정 검증을 완료한 것으로 보지 않습니다.
