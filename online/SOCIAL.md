# 학교용병단 친구 · 친선 아레나

서버 배포 전에 `migrations/0005_school_social.sql`을 적용합니다. `school.mjs`는 `social.mjs`, `arena.mjs`와 최신 `school/engine.js`를 함께 사용합니다. 기존 저장 테이블과 JSON은 유지합니다.

## 단장 이름

첫 이름은 무료, 이후 변경은 보석 3,000개입니다. 공백을 정리하고 NFC 표시 이름을 저장하며, 고유 키는 NFKC·영문 소문자로 비교합니다. 이름 변경 비용·저장 revision·행동 영수증과 고유 이름 변경을 D1 배치 한 트랜잭션으로 확정합니다. 동일 이름을 동시에 요청해도 한 계정만 얻고 실패한 계정은 비용을 내지 않습니다.

기존 사용자 지정 이름은 첫 인증 조회에서 예약합니다. 이전에 중복된 이름이 있으면 먼저 확인한 계정이 예약하며, 다른 계정의 기존 표시 이름·재화·성장은 유지합니다. 이 계정은 `nameNeedsClaim` 및 `me.canName`이 참이고 새 고유 이름을 무료로 정할 수 있습니다. 기본 이름 `새내기 단장`은 친구 기능용 고유 이름으로 사용할 수 없습니다.

## API

`POST /api/school/social`, 헤더 `X-Account-Session`, 본문 `catalogVersion`과 `kind`를 사용합니다.

| kind | 추가 입력 | 동작 |
| --- | --- | --- |
| state | 없음 | 본인 친선 점수·친구·받은/보낸 요청·초대·최근 30개 대전 요약 |
| friend_request | name | 정확한 단장 이름으로 요청 |
| friend_accept | id | 받은 요청 수락 |
| friend_decline | id | 받은 요청 거절 또는 본인이 보낸 요청 취소 |
| friend_remove | id | 친구 제거 및 양쪽 대기 초대 취소 |
| arena_invite | id, requestId | 친구 관계 ID로 2분 초대; 16~80자 요청 ID로 재전송 복구 |
| arena_accept | id | 받은 초대 수락·서버 대전 확정·공유 재생 기록 |
| arena_decline | id | 초대 거절 또는 본인의 초대 취소 |
| arena_match | id | 해당 두 참가자만 전체 재생 기록 조회 |

친구와 요청은 합쳐서 100명까지입니다. 한 쌍에는 요청 하나만 존재합니다. 초대는 분당 최대 5건, 같은 쌍의 활성 초대는 하나입니다. 만료·제거된 친구·타인의 요청 수락·타인의 대전 조회는 거절합니다. 목록에는 전체 저장·계정 식별자·Google 정보·로그인 토큰을 보내지 않습니다. 정기 목록 조회는 전체 재생 데이터와 친구 수만큼의 추가 DB 호출을 하지 않습니다.

## 친선전 규칙

수락 시점 서버에 저장된 출전 용병 최대 6명과 육성 수치로 자동 전투를 계산합니다. 클라이언트의 승자·피해·편성·능력치·시각은 받지 않습니다. 참가자끼리 같은 확정 결과를 재생하며 초대 수락을 중복해도 결과는 한 번만 확정됩니다. 연결이 끊겨도 최근 대전에서 다시 볼 수 있습니다.

- PvP 체력은 기본 수치의 3배, 회복은 75%입니다. 체력 비례 방어막은 확대 전 기본 체력을 기준으로 합니다.
- 3인 역할 시너지, 치명타, 라바 보호·구조 및 오시아 4단계 수룡을 적용합니다. 시작 선공은 서버 난수로 정하고 매초 교대합니다.
- 45초부터 피해가 증가하고 최대 90초입니다. 제한 시간에는 남은 체력 비율의 팀 평균을 비교하며 완전히 같으면 무승부입니다.
- 친선 점수는 승리 +10, 패배 -5, 무승부 0이며 0 미만이 되지 않습니다. 경제 보상이나 경쟁 랭킹이 없는 친선 지표입니다.
- 모험 체력·재화·열쇠·육성 저장은 대전으로 바뀌지 않습니다. 게임 계정 삭제 시 친구 관계와 관련 대전도 삭제됩니다.

`node tests/school-social.cjs`는 실제 SQLite·서명된 테스트 로그인으로 고유 이름 동시 요청, 비용 중복 방지, 친구 동의, 6 대 6 동시 수락·개인 정보·공유 재생·만료·계정 세션을 검사합니다. `node tests/school-server.cjs`, `node tests/accounts.cjs`, `node tests/worker.cjs`는 기존 저장과 카드 대전 회귀입니다. 실제 Google 계정 및 실제 원격 서버의 다중 브라우저 검증과는 구분합니다.
