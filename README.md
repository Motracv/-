# 친구들의 카드 테이블

기존 홈페이지 `index.html`과 독립된 카드 게임입니다. `game.html`은 `game.css`, `engine.js`, `client.js`, 선택적인 `assets/cards/01.webp`~`30.webp`를 사용합니다. 이미지가 없으면 번호·이름을 표시하고 선택 영역에 텍스트 효과를 표시합니다.

## 화면과 규칙

휴대폰은 가로 화면으로 플레이합니다. 세로에서는 회전 안내를 표시하고, 전체화면 버튼은 지원되는 브라우저에서 가로 잠금을 요청합니다. 브라우저가 잠금을 지원하지 않으면 휴대폰을 직접 돌리면 됩니다.

손패는 가로 한 줄, 카드 설명은 짧은 요약과 자세한 설명으로 나눕니다. 최근 사용 카드를 450ms 길게 누르거나 클릭하면 해당 카드 설명을 읽을 수 있습니다. 공격 대상은 선택한 후 사용 버튼으로 확정합니다. 사용 연출·공격 투사체·피해/방어/회복 숫자는 서버의 실제 결과를 따릅니다.

시작·최대 HP는 **100**입니다. AI 연습은 기본 5인 개인전이고 메뉴 → 새 게임에서 2~5명을 선택합니다. 기존 카드 효과 수치는 그대로 유지합니다.

## 뽑기 확률

시작 손패·턴 보충·카드 교환 모두 같은 확률을 사용합니다. 표의 확률은 **해당 등급 카드 한 장당** 확률입니다.

| 등급      | 카드 번호                        | 가중치 | 장당 확률 |
| --------- | -------------------------------- | ------ | --------- |
| 일반      | 07·08·10·12·19·22·30             | 12     | 6.936%    |
| 고급      | 03·04·05·09·11·13·16·20·21·23·29 | 6      | 3.468%    |
| 희귀      | 01·02·14·15·17·27·28             | 3      | 1.734%    |
| 전설      | 18·24                            | 1      | 0.578%    |
| 합성·생성 | 06·25·26                         | 0      | 0%        |

전체 가중치 합은 173입니다. 강한 전체 공격·차례 생략·압수 등을 희귀/전설로 배정했습니다. 상황마다 카드 가치가 달라질 수 있으며 이 등급은 초기 밸런스 설정입니다.

## 온라인 플레이

기존 게임 주소: https://motracv.github.io/-/game.html

**온라인 대전 → 닉네임 → 방 만들기 → 초대 코드 공유 → 입장 → 방장 시작** 순서로 2~5명이 플레이합니다. 기본 공용 서버가 연결되어 있어 참가자가 서버 주소를 따로 입력할 필요가 없습니다.

공용 서버: https://motracv-card-room.densedormouse4.chatgpt.site

Sites의 Cloudflare Worker와 D1에 방 상태를 저장합니다. 클라이언트는 1초 간격으로 자기 상태를 받고, 모든 행동은 서버가 검증한 후 버전 비교로 한 번만 저장합니다. 브라우저에 서버 전체 손패나 난수 상태를 전송하지 않습니다. 공개 접속은 사용자가 명시적으로 승인했습니다.

방은 생성 후 최대 6시간 유지됩니다. 미응답·접속 종료는 다른 참가자의 상태 요청 때 정리됩니다. 모두 접속을 종료한 방은 다음 접근 때 만료/정리됩니다. 영구 대전 기록이나 회원 계정은 저장하지 않습니다.

## 로컬 서버 / 직접 운영

Node.js 20 이상에서 `node server.cjs`로 기존 단일 인스턴스 SSE 서버를 실행할 수 있습니다. 로컬 URL은 `http://localhost:8787/game.html`입니다. 직접 운영 시 HTTPS와 `ALLOWED_ORIGIN=https://motracv.github.io`가 필요합니다. 이 Node 서버는 메모리 저장 방식이라 재시작하면 방이 사라집니다.

공용 서버 소스는 `online/worker.mjs`, SQL은 `online/migrations/0001_rooms.sql`에 있습니다. 배포본은 같은 `engine.js`를 묶어서 사용합니다. Sites 운영 정보는 `online/HOSTING.md`를 참고하세요.

## 온라인 검증과 제한

- 서버가 무작위 수치·턴·반응·대상·소유 카드·revision을 검증하고 개인별 뷰만 전송합니다. 모든 손패를 클라이언트에 보내 숨기지 않습니다.
- 06 사용 중에는 해당 사용자에게만 다른 손패를 공개합니다. 선택한 카드 UID의 실제 소유권을 서버가 재검증합니다.
- 방 코드와 별도로 192비트 개인 복귀 토큰을 발급합니다. 토큰은 URL이 아닌 Authorization 헤더로 전송하며 브라우저 sessionStorage에 저장합니다.
- 턴 45초, 반응/선택 20초. 미응답은 차례 넘김/피해 수용/선물 거절/자동 카드 선택. 접속 상태 갱신이 90초 동안 없으면 탈락하며 같은 탭 새로고침은 복귀합니다.
- 명시적 나가기는 기권입니다. 방장은 대기실에서만 시작할 수 있습니다. 생존자가 한 명이면 승리, 0명이면 무승부입니다.
- 닉네임 기반 친선 게임이며 계정 본인 인증·랭킹·영구 저장은 없습니다. 토큰을 타인에게 공유하지 마세요.

## 확정 판정

사용자가 승인한 추가 판정:

- 17·20·25: 효과 대상자의 다음 2차례 종료까지. 27: 사용 직후~다음 자기 차례 시작 직전.
- 14: 자신은 18~25, 다른 생존자 전원은 10 회복(사용자 추가 확인).
- 18: 다른 최대 2명(2인전 1명), 대상별 천국/지옥 선택. 해당 분류 카드 전부를 사용자 손패로 압수. 표기 효과 수치 합산으로 26 방어력 증가. 범위는 최댓값, 전체 공격은 1인분 수치, 고정 수치 없는 카드는 0.
- 20: 원래 피해를 받으며 일반 뽑기·훔치기·교환·생성·압수 등 모든 카드 획득 금지. 교환은 양쪽 획득 가능할 때만.
- 21: 최대 5 납부, 탈락 확정 후 생존자 무작위 회복. 전원 탈락은 무승부.
- 23·26: 공격받을 때 한 번 피해 차감. 남은 방어력 소멸. Ace는 조건으로만 확인하고 소모하지 않음.
- 24: 건너뛴 차례에도 시작/종료 지속효과 및 기간 처리, 손패 보충 없음. 영역표시는 소모하지 않음.
- 25: 사용하거나 잃어도 회복 금지 지속.
- 15: 무적 및 피해 상한까지 무시.
- 28: 나머지는 현재 차례부터 생존 순서로 1씩 배분. 탈락자 제외.
- 같은 상태는 중첩 대신 기간 갱신. 반격·전가 피해는 재반격·재전가 불가. 전가된 피해에도 무적은 적용.

## 테스트

```sh
node tests/engine.cjs
node tests/server.cjs
node tests/worker.cjs
# Playwright + /usr/bin/chromium 설치 환경:
node tests/landscape.cjs
node tests/online-effects.cjs
# 공개 Pages와 실제 공용 서버 통합 검증:
node tests/deployed-online.cjs
```

브라우저 테스트는 Chromium(`/usr/bin/chromium`)과 Playwright가 필요합니다. 실행 환경에 따라 브라우저 경로를 수정하세요. 외부 서비스 배포 검증과 로컬 통합 검증은 구분해야 합니다.

## 이미지

원본 5개 시트(3열×2행)가 필요합니다. 실제 원본을 받기 전에는 이미지 적용 완료로 간주하지 않습니다. 카드 번호순 파일은 `assets/cards/01.webp`~`30.webp`에 둡니다. 이미지 설명보다 `engine.js`의 텍스트와 판정이 우선합니다.
