# 친구들의 카드 테이블

## 두 번째 게임: 학교용병단

별도 주소 [학교용병단](https://motracv.github.io/-/school.html)에 도트 방치형 수집 RPG를 제공합니다. 기존 `index.html`, 카드게임 화면·전투 엔진은 유지합니다. 물의 용왕 오시아·바람의 무당 라바·UR 호라스·대지 수호 류시온을 포함한 용병 17명, 최대 6인 자동 전투, 12개 구역 60개 지역, 용병 최대 100레벨·단장 최대 200레벨, 훈련·각성, 일일·주간 열쇠 던전, 첫 클리어만 보상을 주는 뫼비우스의 복도, 일일 보급·임무, 최대 8시간 방치 보상을 제공합니다. 모집은 기본 SSR 1%, 60회부터 확률 상승·80회 SSR 확정이며 배너별 50:50과 픽업 실패 후 다음 SSR 픽업 보장을 유지합니다.

휴대폰 가로 보드·다크 모드·모션 설정, 단장 성장·카드 각성·SR/SSR별 모집 연출, 구역별 일반 적 36종과 세 던전 일러스트를 사용합니다. 전투는 1.0×·1.5×를 선택하며 라바의 보호·치유와 오시아 수룡 컷인을 지원합니다. 계정 단장 이름·레벨·복도 기록을 공개 랭킹에 표시하고 Google 신원과 전체 저장은 공개하지 않습니다. 게스트는 목록을 볼 수 있지만 순위에는 서버 계정 기록만 반영합니다. 성장 조정 후에도 기존 보유 용병·레벨·재화·진행·모집 누적과 보장을 보존합니다.

훈련 비용은 `50 + 16L + 2L²`로 낮추고 기존 경험치 성장 기준을 유지합니다. 그리기는 약 60fps를 목표로 정적 그림과 바뀌지 않은 UI 값을 재사용하며, 모든 기기의 성능을 보장하지는 않습니다. 육성·설정 창을 연 채 던전을 끝내도 결과와 다음 층에 접근할 수 있습니다.

설정에서 **PWA 앱 설치·홈 화면 추가** 안내를 제공합니다. 지원하는 Chrome·Edge 또는 iOS Safari에서 사용하며 APK·앱스토어 배포는 아닙니다. 처음 온라인에서 파일 준비를 마친 게스트는 오프라인으로 실행할 수 있고, Google 로그인·계정 저장·랭킹에는 인터넷이 필요합니다. 카탈로그는 21이며 게스트 저장 키 `school-mercenaries-v8`와 기존 기록을 유지합니다.

친구에게 파일로 전달할 수 있는 [Windows용 ZIP 다운로드](https://motracv.github.io/-/downloads/)도 제공합니다. 압축을 풀고 EXE를 실행하면 PC에 설치된 Edge·Chrome의 게임 전용 창을 엽니다. Windows 10/11 x64용 실행기이며 게임·브라우저 전체 번들 또는 코드 서명된 설치 프로그램은 아닙니다. [실행기 소스·빌드 안내](desktop/windows/README.md)를 참고하세요.

게임 내용과 저장 구조·확률·검증 방법은 [학교용병단 개발 안내](school/README.md)를 참고하세요. `npm start` 후 `http://localhost:8787/school.html`에서 게스트 플레이를 실행할 수 있습니다. 온라인 계정 진행은 기존 계정 서버의 `/api/school/*`에 별도로 저장합니다.

## 길드 보스: 사슬의 벌룬

**길드 → 길드 보스**에서 1~5명이 같은 전투방에 모여 90초 자동 전투를 진행합니다. 각자 현재 편성 최대 6명을 출전시키며 혼자서도 시작할 수 있습니다. 기본 HP는 50,000,000, 물리 피해는 0이며 마법·치유 역할과 호라스의 공격이 마법 피해를 줍니다. 대기실의 편성 표시로 구분할 수 있습니다.

전투 시작 시 계정당 1회 사용, 한국 시간 자정에 하루 5회로 초기화합니다. 날짜 변경·재접속·길드 이동은 누적 피해나 이미 사용한 횟수를 되돌리지 않습니다. 보스 HP는 길드 전체가 공유하며 토벌 뒤 다음 벌룬을 열 수 있습니다. 방은 길드당 하나이며, 전투 중에는 참가자의 부대를 눌러 전환해 봅니다. 피해·확률·기여도·보상은 서버가 계산하고 클라이언트의 피해량을 받지 않습니다.

## 길드 · 프로필 · 골드 수급 업데이트

메인 깃발에서 최대 30명 길드를 만들고 단장 이름으로 초대합니다. 길드 이름은 3~16글자이며 학교 교실, 세 가지 문장, 공지, 단원 목록, 길드장 위임·강퇴·탈퇴를 지원합니다. 가입 다음 한국 날짜부터 계정당 매일 보석 30개를 출석으로 받을 수 있습니다. 길드 교실에서 벌룬 보스전에 도전할 수 있습니다.

왼쪽 위 단장 프로필에서 여섯 새 초상화 또는 대표 용병을 선택합니다. 기존 저장에는 능력치 없는 **베타테스터** 칭호가 열리며 장착 여부를 고를 수 있습니다. 모험·던전·새 방치 적립·퀘스트·단장 레벨업·일일 보급의 골드는 기존 기준 **2.6배**이며 정수로 반올림합니다. 기존 잔액, 이미 적립한 방치 보상, 쿠폰·이벤트 교환의 고정 금액, 가격과 보석은 유지합니다. 반복 처치 목표는 100→75마리로 줄이고 진행도를 보존합니다.

## 반격 · 전투 피드백 업데이트

모험·던전에서 일반 적이 공격하면 18%, 보스가 공격하면 32% 확률로 **반격** 버튼을 표시합니다. 기회 간격은 최소 10초이며, 전투 속도와 관계없이 실제 3.5초 안에 누르면 가장 공격력이 높은 생존 용병이 공격력 180%의 추가 공격을 합니다. 기존 피해 배율·방어 판정을 적용하고 받은 공격을 취소하지는 않습니다. 누르지 않아도 기존 자동 전투와 보상은 그대로 이어지며, 아레나에는 적용하지 않습니다.

피해·회복·보호막 흡수는 실제 적용된 양을 별도 색상으로 표시합니다. 같은 순간에 같은 대상에게 들어간 같은 종류의 수치는 합산합니다. HP 바의 회복 보간과 피해 잔상은 표시 전용이며 실제 체력·탈락 판정은 즉시 반영합니다. 로그인 계정의 반격 기회·유효 시간·피해·결과는 서버에서 검증하고, 중복 요청과 재시도로 피해·보상이 중복되지 않게 합니다.

`npm run test:school:counter`는 기존 저장·만료·속도·보상·표시 수치와 실제 계정 API의 동시 요청·응답 유실 재시도를 검사합니다. `npm run test:school:counter-browser`는 568×280·755×330·2560×1440 화면의 버튼, HP 애니메이션, 계정 분리와 새로고침을 검사합니다. 설치 업데이트·오프라인 캐시도 검증합니다. CPU 4배 감속 브라우저에서 평균 약 55회/초 그리기를 확인했으며, 실제 휴대폰의 고정 프레임을 보장하는 수치는 아닙니다.

## 던전 장비 업데이트

일일 던전 승리는 장비1개, 주간 던전은2개, 뫼비우스는 처음 돌파한5층 단위 보스에서1개를 얻습니다. 난이도가 높을수록 SR·SSR 확률이 올라갑니다. **출전 용병 클릭 → 장비**에서 무기·방어구·장신구3부위를 장착하고 남는 같은 장비로 최대5단계 각성합니다. 장비 레벨업이나 골드 비용은 없습니다.

중복 장비는 여러 용병에게 나눠 장착할 수 있으며, 같은 종류의 각성 단계는 공유합니다. 착용 중인 수량을 재료로 소비하지 않습니다. 장비 보너스는 다음 전투부터 적용하며, 세 부위 SSR최대각성 기준 공격력+9%·체력+14%입니다. 던전 진행 중에는 장비를 바꿀 수 없고, 시즌 방어 편성은 아레나에서 갱신해야 새 장비를 반영합니다. 기존 용병·재화·모집 누적·편성은 유지합니다.

## 편성·파밍·시즌 업데이트

- **편성 → 프리셋**: 모험·보스·아레나용 3칸에 현재 편성과 순서를 저장하고 이름을 바꿉니다. 불러오면 현재 모험 전투가 다시 시작되며 던전 진행 중에는 적용할 수 없습니다.
- **모험 지도 → 파밍 추천**: 현재 팀의 레벨·각성·속도로 정상 보상 지역을 별도 Worker에서 계산하고 안정적인 상위 3곳을 추천합니다. 미리보기는 저장과 재화를 변경하지 않습니다.
- **안뜰 또는 설정 → 패치 노트**: 최신 변경 사항과 읽지 않은 업데이트 표시를 확인합니다.
- **모집·겨울 이벤트·시즌전**: 실제 종료 시각의 남은 시간을 표시합니다. 라바는 한국 시간 11월20일23:59까지, 종료일이 정해지지 않은 호라스·겨울 이벤트는 ‘종료일 미정’, 오시아는 상시입니다.
- **아레나 → 시즌전**: Google 계정과 고유 단장 이름으로 방어 편성을 등록합니다. 4주 시즌, 한국 자정마다 하루5회, 같은 상대 하루1회이며 전투력이 비슷한 실제 참가자와 비동기 자동 대결합니다. 승리+20·패배−10·무승부0, 방어전은 점수를 잃지 않습니다. 첫 시즌은 2026년12월16일00:00에 종료됩니다. 기존 친구 초대는 **친선전** 탭에 있습니다.

시즌마다 1,000점으로 시작합니다. 종료 전 5회 이상 도전하면 최종 티어에 맞는 칭호와 테두리를 자동으로 받아 **보상** 탭에서 착용할 수 있습니다. 브론즈 1,100점 미만·실버 1,100점·골드 1,250점·다이아 1,450점부터이며 재화 보상은 없습니다. 참가자가 없으면 빈 목록을 표시하며 임의의 봇을 실제 플레이어로 표시하지 않습니다. 기존 모집 확률·천장·픽업 보장은 변경하지 않습니다.

## 겨울 업데이트 · 친구 아레나

[학교용병단](https://motracv.github.io/-/school.html)에 연속 레벨업, 치명타 도트 표시·피격 반동·타격음, 전투 기여도, 라바의 부채 모션과 오시아 수룡 자세, 정면 모집 애니메이션을 추가했습니다. 작은 HUD와 중립 다크 모드로 전장을 넓혔으며 Pretendard/Galmuri는 포함된 SIL OFL 라이선스를 따릅니다. 부하가 큰 기기에서는 전투 캔버스의 렌더링 해상도를 조절하고 UI 글씨·버튼은 원래 해상도를 유지합니다. 실제 기기별 고정 60fps를 보장하지 않습니다.

고유 단장 이름을 정하고 친구 요청을 수락한 뒤 1대1 친선 아레나에 초대할 수 있습니다. 최대 6명씩 출전하며 **서버 저장 편성으로 계산한 자동 대전**을 양쪽에서 재생합니다. 친구 초대는 2분간 유효합니다. 승패·딜량은 서버에서 확정하고 재화 보상은 없습니다. 첫 이름은 무료, 이후 변경은 3,000보석입니다. 로그인은 브라우저를 닫아도 유지하며 내 계정에서 로그아웃할 수 있습니다.

겨울 축제는 승리 시 20% 확률로 눈송이(일반 1개·보스 2개)를 얻어 제한된 보석·코인 상품에 교환합니다. 오프라인 보상 및 이미 깬 복도 층은 눈송이를 추가 지급하지 않습니다. 보급소 코드 **MAJORUPDATE**로 보석 3,000개를 1회 받습니다. 수호·딜러·치유를 각각 3명 편성하면 방어·공격·회복 보너스가 생기고, 후반 일반 적도 근접·원거리·치유 기술을 사용합니다. 정확한 수치와 API·검증은 [게임 안내](school/README.md), [소셜 서버](online/SOCIAL.md), [검증 기록](VALIDATION.md)에 있습니다.

## Google 계정 · 레벨

**메뉴 → 내 계정**에서 Google 계정으로 경험치와 전적을 저장하도록 구현했습니다. 레벨·칭호는 표시용이며 HP100, 카드 효과와 뽑기 확률에는 영향을 주지 않습니다. 닉네임으로 참가하는 게스트 대전도 유지합니다.

운영자의 Google OAuth 클라이언트 ID를 서버의 `GOOGLE_CLIENT_ID`에 등록해 **Google 로그인을 활성화했습니다**. 실제 공개 게임에서 Google 공식 버튼을 누르면 `motracv.github.io`로 연결되는 Google 로그인 화면이 열리는 것을 확인했습니다. 본인 계정 로그인 완료·재접속 및 서로 다른 실제 Google 계정의 경험치 지급은 추가 운영 확인 대상입니다. [연결 설정 안내](online/GOOGLE_LOGIN.md)를 참고하세요. 클라이언트 보안 비밀번호는 사용하지 않습니다.

온라인 완주30 XP·승리 추가50 XP·무승부 추가10 XP입니다. 로그인한 참가자2명 이상, 경기60초 이상, 본인의 카드 사용·방어·교환·합성2회 이상이 조건이며 기권·연결 종료와 AI 연습에는 경험치를 주지 않습니다. 결과 창에 획득 경험치와 레벨업을 표시합니다. 시작은 Lv.1, Lv.2까지100 XP이며 이후 요구 경험치가50씩 증가합니다. 방에는 닉네임·레벨·칭호만 공개합니다.

Google 실명·이메일을 저장하지 않고 계정 식별자의 해시와 게임 계정·경기 결과만 저장합니다. 서버의 확정 결과를 고유 경기별로 한 번만 원장에 기록합니다. 같은 계정의 한 방 중복 참가, 위조 인증, 클라이언트 XP 조작을 거부합니다. 로그인 세션은 서버에 해시로 보관하며 로그아웃·계정 삭제를 지원합니다. 자세한 보관 정책은 [개인정보 안내](privacy.html)를 확인하세요.

## 효과음

`sound.js`가 Web Audio로 24종의 짧은 효과음을 직접 합성합니다. 음원 파일이나 외부 다운로드가 필요하지 않습니다. 타격·강한 타격·방어·회복·정화·저주·카드 이동·휴대폰·야구공·필드·희귀 카드·승패 등에 서로 다른 소리를 사용합니다. 실제 방어 성공에는 방어음을, 실제 피해에만 타격음을 연결합니다.

기본 볼륨은 40%입니다. 상단 **♪** 버튼으로 음소거하고, **메뉴 → 효과음**에서 볼륨을 조절하거나 미리 들을 수 있습니다. 설정은 브라우저에 저장됩니다. 첫 터치/클릭/키 입력 후 재생하며, 음소거하거나 탭이 숨겨지면 진행 중인 소리를 정리합니다. 재접속·새 게임에서는 과거 소리를 몰아서 재생하지 않습니다. 낮은 HP 경고는 10 이하로 진입할 때 한 번, 승패 소리도 결과가 처음 나타날 때 한 번만 재생합니다.

Web Audio를 지원하지 않거나 재생을 허용하지 않는 환경에서도 게임은 계속 진행됩니다. 자동재생 제한, 기기 볼륨과 실제 스피커 상태는 브라우저·기기 설정의 영향을 받습니다.

## 전투 연출과 결과 화면

40장에 각각 연출 프로필을 연결했습니다. 휴대폰 회전 투척, 야구공, 층이 있는 햄버거, 주사위, 방패, 카드 뒷면 이동, 저주 봉인, 회복 날개 등을 `effects.js`와 `effects.css`로 표시합니다. CSS 3D와 브라우저 애니메이션을 사용하며 외부 모델이나 WebGL은 필요하지 않습니다. 카드 사용·공격 이동과 실제 피해·방어 결과를 분리해 서버가 확정한 결과를 보여줍니다.

HP 25 이하에는 붉은 위기 표시, 10 이하에는 더 강한 가장자리 효과를 적용하며 회복·탈락·새 게임 때 해제합니다. 지금 사용할 수 없는 카드는 어둡게 표시하지만 눌러서 설명과 불가 사유를 확인할 수 있습니다. 방어 카드도 공격을 받으면 사용 가능한 표시로 바뀝니다. 사용할 수 있으나 효과가 없는 카드와 실제 사용 금지는 구분합니다.

개인 탈락에는 관전 안내를, 대전 종료에는 승리·패배·무승부 결과 화면을 표시합니다. 닫은 결과는 매 서버 조회마다 다시 열리지 않으며 상단 결과 버튼으로 다시 볼 수 있습니다. AI는 바로 다시 시작하고, 온라인은 종료된 방을 나간 뒤 새 방 생성·입장 화면으로 이동합니다.

운영체제의 움직임 줄이기 설정을 따르며, 피해·회복 숫자와 결과 설명은 유지합니다. 전투 연출은 조작 영역을 차단하지 않고, 새 게임에서는 진행 중인 전투 애니메이션을 취소합니다.

기존 홈페이지 `index.html`과 독립된 카드 게임입니다. `game.html`은 `game.css`, `engine.js`, `client.js`, 선택적인 `assets/cards/01.webp`~`40.webp`를 사용합니다. 이미지가 없으면 번호·이름을 표시하고 선택 영역에 텍스트 효과를 표시합니다.

## 화면과 규칙

휴대폰은 가로 화면으로 플레이합니다. 세로에서는 회전 안내를 표시하고, 전체화면 버튼은 지원되는 브라우저에서 가로 잠금을 요청합니다. 브라우저가 잠금을 지원하지 않으면 휴대폰을 직접 돌리면 됩니다.

남색 듀얼 전장에 손패를 가로 한 줄로 배치합니다. 공격·방어·회복·마법·필드·특수는 색상 띠와 아이콘·글자로 구분하고, 행동 버튼은 작게 모았습니다. 카드 설명은 짧은 요약과 자세한 설명으로 나눕니다. 최근 사용 카드를 450ms 길게 누르거나 클릭하면 해당 카드 설명을 읽을 수 있습니다. 공격 대상은 선택한 후 사용 버튼으로 확정합니다. 카드를 쓰면 사용자와 카드 이름을 크게 표시하고, 공격 투사체·피해/방어/회복 숫자와 최근 처리 결과를 보여 줍니다. 회복에는 화면 전체의 초록빛과 HP 강조 효과를 적용합니다. 활성 필드는 별도 칸에서 이름·남은 발동 횟수 또는 대상과 함께 계속 표시합니다. 모든 전투 연출은 서버의 실제 결과를 따릅니다.

시작·최대 HP는 **100**입니다. AI 연습은 기본 5인 개인전이고 메뉴 → 새 게임에서 2~5명을 선택합니다. 기존 카드 효과 수치는 그대로 유지합니다.

## 뽑기 확률

시작 손패·차례 보충·카드 교환 모두 서버가 같은 **가중치 규칙**으로 추첨합니다. 공격 카드가 지나치게 적었던 문제를 줄이기 위해 공격 계열의 기본 가중치를 2배로 올렸습니다. 아래 값은 **각 카드 한 장당 기본 가중치**이며, 확률은 가중치를 전체 합으로 나눈 값입니다.

| 등급 | 카드 번호 | 공격 계열 가중치 | 그 밖의 가중치 |
| --- | --- | ---: | ---: |
| 일반 | 07·08·10·12·19·22·30·31·35·40 | 24 | 12 |
| 고급 | 03·04·05·09·11·13·16·20·21·23·29·33·36 | 12 | 6 |
| 희귀 | 01·02·14·15·17·27·28·32·34·37·38·39 | 6 | 3 |
| 전설 | 18·24 | 해당 없음 | 1 |
| 합성·생성 | 06·25·26 | 0 | 0 |

기본 전체 가중치는 **311**, 공격 계열 합은 **150**이므로 보정 전 공격 계열 확률은 **48.23%**입니다. 공격 계열은 01·07·09·11·15·31·33·34·35·36·37·38로, 직접 공격뿐 아니라 Ace 필드와 팬티의 지속 피해도 포함합니다. 같은 역할에서는 일반 → 고급 → 희귀 → 전설 순으로 나오기 어렵습니다. 06·25·26은 어떤 보정에서도 일반 뽑기에 나오지 않습니다.

손패에 따라 다음 한 장의 가중치를 다시 조정합니다.

- 공격 계열 0장 **또는** 방어 계열 3장 이상: 공격 계열 가중치 추가 2배.
- 공격 계열 0장 **동시에** 방어 계열 3장 이상: 공격 계열 가중치 추가 3배.
- HP 30 이하이고 회복 금지 상태가 아닐 때: 회복 계열 08·14·40의 가중치 추가 2배.

보정은 카드를 한 장 얻을 때마다 다시 계산합니다. HP가 30보다 높다면 공격 계열 0장일 때 다음 뽑기 공격 확률은 **65.08%**, 공격 0장·방어 3장 이상일 때는 **73.65%**입니다. 필요한 카드를 확정 지급하는 방식은 아니므로 같은 종류가 연속으로 나올 수 있습니다. 손패 위에 활성 보정을 표시하며, 카드 상세와 규칙의 개별 확률은 **보정 전 기본 확률**입니다. 다른 사람의 손패로 내 확률을 계산하지 않습니다.

뽑기·화면에 쓰는 역할은 카드의 원래 종류를 바꾸지 않습니다. 34번은 피해를 주는 **마법**, 40번은 회복하는 **마법**입니다. 18번의 압수나 16번의 행동 제한은 기존의 카드 종류 기준을 유지합니다. 경쟁 승률과 최적 밸런스를 보장하는 설정은 아니며 실제 플레이 결과에 따라 확률을 조정할 수 있습니다.

## 로컬 서버 / 직접 운영

Node.js 20 이상에서 `node server.cjs`로 기존 단일 인스턴스 SSE 서버를 실행할 수 있습니다. 로컬 URL은 `http://localhost:8787/game.html`입니다. 직접 운영 시 HTTPS와 `ALLOWED_ORIGIN=https://motracv.github.io`가 필요합니다. 이 Node 서버는 메모리 저장 방식이라 재시작하면 방이 사라집니다.

공용 서버 소스는 `online/worker.mjs`·`online/accounts.mjs`, SQL은 `online/migrations/`에 있습니다. 배포본은 같은 `engine.js`를 묶어서 사용합니다. 계정 기능은 D1 공용 Worker에 있으며 로컬 메모리 SSE 서버는 게스트 연습용입니다. Sites 운영 정보는 `online/HOSTING.md`를 참고하세요.

- 32: 지정한 대상 **자신**이 현비가 됩니다. 대상의 다음 자기 차례 종료까지 다른 사람의 상대 지정 공격과 전체 공격이 현비 한 명에게 향합니다. 전체 공격 피해는 여러 사람 몫으로 배수 계산하지 않습니다. 현비 자신의 공격은 정상적으로 다른 상대에게 향하고, 새 현비를 지정하면 이전 도발은 해제됩니다.
- 33: 피해 8은 50%, 16은 30%, 32는 10%, 64는 0.1%, 100은 0.01%. 합계에서 남은 9.89%는 빗나감(피해 0)입니다. 이 결과와 독립적으로 50% 확률로 반격 불가가 붙으며 일반 방어는 가능합니다.
- 34: 대상의 자기 차례 종료를 두 번 셀 때마다 피해 10. 상태 해제 카드로 없앨 때까지 지속합니다. 같은 상태를 다시 부여하면 중첩하지 않고 주기를 갱신합니다.
- 38: 사용 직후부터 다음 자기 차례 시작 전까지, 직접 공격으로 실제 HP 피해를 받으면 공격자에게 5 피해를 돌려줍니다. 원래 피해도 받습니다. 반격·전가·지속 피해에는 재발동하지 않습니다.
- 39: 사용자 포함 사용 직전 생존자 중 최고·최저 HP를 정합니다. 동률은 각각 무작위 한 명입니다. 최고에게 피해를 적용한 뒤 최저를 회복하며, 최대 HP 100과 탈락자 부활 금지를 지킵니다.
- 40: 자신에게 적용하고 다음 두 자기 차례 시작에 HP 5씩 회복합니다. 건너뛴 차례에도 지속효과를 처리하며, 회복 금지는 정상 적용됩니다.

18번이 새 공격 카드를 압수하면 방어력 합산값은 31=8, 33=100, 35=9, 36=30, 37=20, 38=15입니다. 34·40은 마법이므로 천국/지옥 압수 대상이 아닙니다.

## 이미지
